# Exact pins for every direct runtime/dev dependency, verified against the
# full test suite (588 tests, python -m pytest -q) on this exact set before
# being committed. Direct dependencies are pinned exactly (`==`) so a fresh
# `pip install -r requirements.txt` reproduces the same environment on any
# machine, including a clean Azure deployment (App Service/VM/Container) --
# not just "some version >= X that happened to work here." Transitive
# dependencies are intentionally left to pip's normal resolver rather than
# pinned by hand here: doing that correctly needs a dedicated lock-file tool
# (e.g. pip-compile/uv) run against this exact list, which this repository
# does not currently use -- pinning transitive packages by guesswork risks
# locking in an incompatible combination nobody actually verified.
#
# To refresh these pins after a deliberate upgrade: install the new
# version, run the full suite (`python -m pytest -q`), then update the
# pinned number here to match what was actually installed and verified --
# never bump a version number without re-running the suite against it.

# --- Core service ----------------------------------------------------------
# tzdata: Python's zoneinfo (used for every per-patient IANA timezone
# calculation, see memory/service.py and tools/builtin.py) has no bundled

# missing here entirely; the previous requirements.txt only worked in an
# environment that happened to already have it installed some other way,
# which a genuinely clean install (verified in a fresh venv) does not.
